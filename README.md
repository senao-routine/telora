# Telora 🎬

Mac / Windows で動作する、本格派のシンプル動画編集ソフトです。
**複数トラックのタイムライン**上に動画・画像・テロップを配置し、カット編集や
字幕（テロップ）挿入ができます。Filmora のような操作感を目指した Electron + FFmpeg 製。

## 主な機能

### タイムライン / 編集
- 🎞 **複数トラック（Filmora 風レイアウト）** — 上から テロップ／オーバーレイ（画像）／メイン動画／**音声**。映像が上・音声が下
- ➕ **レイヤ追加自在** — テロップ層・画像層・音声層を何層でも追加／削除可能
- 🖼🎵 **動画・画像・音声を配置** — 動画/画像クリップの混在に加え、**BGM やナレーションの音声クリップ**を音声トラックへ
- ✂ **カット編集** — 再生位置で分割、**再生線より前をカット / 後ろをカット**、トリミング・並べ替え
- 📑 **Alt（Option）+ドラッグでクリップ複製**
- 🧲 **スナップ** — クリップ端・再生位置に吸着して正確に配置
- 🅣 **テロップ** — 文字／フォント／サイズ／色／フチ／背景／影／整列／位置／表示時間を編集。プレビュー上でドラッグ移動
- 🎨 **テロップのデザインプリセット 8種** — シンプル白／太フチ白／黄色強調／黒帯字幕／ニュース風／ポップ赤／ネオン緑／ミニマル黒
- ✨ **テロップアニメーション** — フェード／スライド（上下左右）／ポップ／ズーム／タイプライター（プレビューで完全再現。書き出しはフェードで反映）
- 🔁 アンドゥ / リドゥ、ズーム、タイムライン高さ調整、キーボードショートカット多数

### 取り込み / 書き出し
- 📁 **メディアビン** — 読み込んだ素材（動画・画像）を種類バッジ付きで一覧表示。ドラッグ＆ドロップ対応
- 🎙 **音声から文字起こし → テロップ自動生成** — ローカル Whisper（whisper.cpp / openai-whisper を自動検出）で音声を文字起こしし、タイムタグ付きテロップを自動生成（オフライン・無料）
- 💬 **SRT / WebVTT 字幕の取り込み** — 字幕ファイルからテロップを一括生成（複数行・タグ除去対応）
- 🎬 **XML（FCP7 / Premiere の xmeml）取り込み** — 既存の編集データからクリップを復元
- 👁 **リアルタイムプレビュー** — 動画・画像・テロップを実際の合成結果で確認（WYSIWYG）
- 🎞 **幅広いコーデックに対応** — プレビューはキャンバス合成方式。ブラウザが復号できない形式（HEVC/H.265・ProRes 等）は **FFmpeg でフレーム抽出して表示**するため、どんな素材でも映像が映ります
- ⤴ **MP4 書き出し** — カット・隙間（黒）・画像・テロップ・音声をまとめて 1 本の動画に出力
- 💾 プロジェクトの保存・読み込み（`.tceproj`）。旧バージョンのプロジェクトも自動移行

プレビューと書き出しはテロップ・画像の描画ロジックを共有しているため、**見たままが書き出されます**。

## 必要なもの

| ツール | 用途 | 備考 |
|--------|------|------|
| [Node.js](https://nodejs.org/) 18+ | 実行・ビルド | 動作確認は v24 |
| [FFmpeg](https://ffmpeg.org/) / FFprobe | 書き出し・メタ情報取得 | **PATH に必要**（`ffmpeg -version` で確認） |
| Whisper（任意） | 文字起こし機能 | `brew install whisper-cpp` ＋ ggml モデル（`~/.cache/whisper/` 等に配置）、または `pip install openai-whisper`。未導入でも他機能は使用可 |

> 編集・プレビューは FFmpeg 無しでも可能ですが、**書き出しには FFmpeg が必須**です。
> macOS: `brew install ffmpeg` / Windows: 公式バイナリを PATH に追加。

## セットアップと起動

```bash
npm install      # 依存関係（Electron）を取得
npm start        # アプリを起動
```

配布用インストーラ（任意）:

```bash
npm run dist:mac   # macOS (.dmg)
npm run dist:win   # Windows (.exe / NSIS)
```

## 使い方

1. **素材を読み込む** — 「素材読込」、ウィンドウへドラッグ＆ドロップ、またはメディアビンの ＋。
   読み込んだ動画・画像は自動でメイントラックに追加されます。
2. **配置する** — クリップをドラッグして移動、端のハンドルでトリミング。画像はオーバーレイトラックにも配置可（メディアをトラックへドロップ）。
3. **カットする** — 再生位置（赤い線）を合わせて「分割」(S)、「前をカット」(A)、「後をカット」(D)、不要クリップは Backspace。
4. **テロップを入れる** — 「テロップ追加」(⌘/Ctrl+T)。右パネルで文字や見た目を編集し、プレビュー上でドラッグして位置調整。
   既存の **SRT** 字幕や、編集データの **XML** も取り込めます。
5. **書き出す** — 「書き出し」(⌘/Ctrl+E)。出力解像度を選び保存先を指定すると MP4 が生成されます。

### キーボードショートカット

| キー | 機能 | キー | 機能 |
|------|------|------|------|
| `Space` | 再生 / 一時停止 | `S` | 分割 |
| `A` | 前をカット | `D` | 後をカット |
| `Backspace` | 選択を削除 | `Alt`+ドラッグ | クリップ複製 |
| `←` / `→` | 1 フレーム移動 | `Shift+←/→` | 1 秒移動 |
| `Home` / `End` | 先頭 / 末尾へ | `⌘/Ctrl+Z` | 元に戻す |
| `⌘/Ctrl+S` | 保存 | `⌘/Ctrl+O` | 開く |
| `⌘/Ctrl+I` | 素材読込 | `⌘/Ctrl+E` | 書き出し |
| `⌘/Ctrl + ホイール` | タイムライン拡大縮小 | | |

## 仕組み（アーキテクチャ）

```
src/
├─ main/                 … Electron メインプロセス
│  ├─ main.js            … ウィンドウ・メニュー・IPC・ファイルダイアログ
│  ├─ preload.js         … contextBridge による安全な API 公開
│  └─ export.js          … FFmpeg 書き出し（連結＋黒埋め＋PNG重畳）・ffprobe
└─ renderer/             … 画面（UI）
   ├─ index.html / styles/main.css
   └─ js/
      ├─ state.js        … 中央ステート（複数トラックモデル）・履歴・イベントバス
      ├─ media.js        … 動画/画像の読み込み・サムネイル・メディアビン
      ├─ preview.js      … キャンバス合成プレビュー（動画/画像/オーバーレイ/テロップ）
      ├─ timeline.js     … 複数トラックの描画と操作（配置/移動/トリム/スナップ）
      ├─ inspector.js    … クリップ種別ごとのプロパティ編集
      ├─ edit.js         … 分割 / 前後カット / 削除 / テロップ追加
      ├─ render-telop.js … テロップ描画（プレビューと書き出しで共通）
      ├─ import-srt.js   … SRT / WebVTT 取り込み
      ├─ import-xml.js   … FCP7/Premiere xmeml 取り込み
      ├─ export-ui.js    … 書き出し UI・レイヤ収集・進捗
      └─ project-io.js   … プロジェクト保存 / 読み込み（v1→v2 移行）
```

**書き出しの要点**：メイントラックを「タイムライン順のセグメント連結（隙間は黒＋無音で補填）」で構築し、
すべてを `pts 0` 始まりに揃えて `overlay` の同期問題を回避。最後にテロップ・オーバーレイ画像を
出力解像度のフルフレーム透過 PNG として `overlay ... enable='between(t,開始,終了)'` で重畳します。
日本語フォントや装飾もプレビュー通りに書き出されます。
