# モデル③ アプリ内AIチャット版 — 設計

**位置づけ**: Telora 内に自然言語チャット欄を持ち、「無音消してテロップ付けて、最初の10秒はカット」のように指示するとLLMが**編集コマンド列**へ変換して実行する。
**思想**: 一番"魔法"に見えるが LLM が必要。**外部API（オプトイン）またはローカル軽量モデル**を選べる設計とし、無料/オフライン方針と両立させる。

**②との関係**: ③は②と**同じ編集コマンド層（EditCommands）を内部APIとして共有**する。違いは「誰がコマンドを発行するか」だけ（②=外部エージェント、③=アプリ内LLM）。

---

## 1. アーキテクチャ全体

```
┌ Renderer ─────────────────────────────────────────────────┐
│ chat-panel.js（右ドック or 下段のチャットUI）                     │
│   ユーザー入力「無音消してテロップ付けて」                          │
│        │                                                   │
│   会話オーケストレータ                                          │
│     1) getTimeline で現状コンテキスト取得（EditCommands）           │
│     2) LLM に「ツール定義 + 現状 + 指示」を渡す                     │
│     3) LLM が function call（= EditCommands のツール）を返す        │
│     4) 破壊的なら確認 → EditCommands.run() で実行 → 結果を会話へ      │
│        │                              │                     │
│   llm-adapter.js（プロバイダ抽象）        EditCommands（00章・②と共有） │
│     ├─ external: window.api.llmChat()  → main が fetch         │
│     └─ local:    ローカルモデル（任意）                          │
└────────────────────────────┼──────────────────────────────┘
                             │ window.api.llmChat（preload 追加）
┌────────────────────────────▼──────────────────────────────┐
│ Main：llm-proxy.js                                          │
│   外部API（Anthropic/OpenAI互換）へ HTTPS（APIキーは main で保持）    │
│   またはローカル推論（llama.cpp 等）へ転送                          │
└───────────────────────────────────────────────────────────┘
```

**鍵**: LLM には「自由文を実行させない」。**EditCommands のツール定義（function calling スキーマ）**を渡し、LLM はツール呼び出しの列を返すだけ。実行は EditCommands が握る＝安全・決定的・undo可能。

---

## 2. チャットUIと会話フロー

- **配置**: インスペクタ横の新ドック、または下段の開閉パネル。メッセージ履歴＋入力欄＋「実行前に確認する」トグル。
- **1ターンの流れ**:
  1. ユーザー発話を受領。
  2. `getTimeline`/`getTranscript` で**現状スナップショット**を作りプロンプトに同梱。
  3. LLM へ：システムプロンプト（役割・制約）＋ツール定義（EditCommandsカタログ）＋現状＋ユーザー指示。
  4. LLM応答が **tool_calls** なら：破壊的（delete/cut/move/export）は**ダイフ表示で確認**→承認後 `EditCommands.run()`。読み取り（get_*）は即実行。
  5. 実行結果（要約 + 変化点）を会話に追記。必要なら 2〜5 をループ（複合指示）。
  6. 連続実行は1つの履歴グループにまとめ、チャットの各ターン末に「↩ この操作を取り消す」を提示。

- **プレビュー/確認**: 破壊的操作は実行前に「何を・何箇所・何秒変えるか」を提示（例「無音 12箇所・合計8.3秒を削除します」）。`pushHistory` 済みなので承認後でも Cmd+Z で戻せる。

---

## 3. LLMプロバイダ抽象（llm-adapter / llm-proxy）

- **インターフェース**: `chat({messages, tools}) → {text?, toolCalls?[]}` の1関数に抽象化。
- **プロバイダ**:
  - `external`：Anthropic Messages API（tools対応）や OpenAI互換。**APIキーは main プロセスで保持**し、renderer には出さない。呼び出しは `window.api.llmChat()`（preload 追加）→ main が `fetch` で HTTPS。
  - `local`（任意）：ローカル推論サーバ（llama.cpp / Ollama 等）に同インターフェースで接続。完全オフライン。品質はモデル依存。
- **設定**: 設定画面でプロバイダ選択・モデル名・APIキー入力・ローカルエンドポイント。
- **キー管理**: APIキーは main の userData 配下に保存（renderer/プロジェクトファイルには保存しない）。可能なら OS キーチェーン（`keytar` 等）。**コミット対象外**。
- **オフライン挙動**: external 選択かつ未接続 → チャットは無効化し「ローカルモデルか手動編集をご利用ください」を表示。決定的な編集機能（無音カット等）は LLM 無しでも従来どおり使える。

---

## 4. NL → 編集コマンド変換（function calling）

- LLM には EditCommands カタログ（00章）を **function/tool 定義**として渡す。各ツールに厳密な JSON Schema を付け、引数のハルシネーションを抑止。
- **時刻・対象の解決**: 「最初の10秒」→ `{time:0..10}`、「2番目のクリップ」→ getTimeline の結果から clipId を LLM に解決させる（現状を渡しているので可能）。曖昧なら LLM に聞き返させる（確認ターン）。
- **複合指示**: 「無音消してテロップ付けて」→ `cut_silence`（各clip）＋ `add_telop` or 文字起こし起動の複数ツール呼び出し。オーケストレータが順に実行し、各結果を次の判断材料として返す。
- **安全策**: 1ターンのツール実行回数に上限、`export`/`delete_*` は必ず人間承認、未知ツール名は拒否。

## 5. ②との共有と差分

| | モデル② MCP | モデル③ チャット |
|---|---|---|
| コマンド発行者 | 外部エージェント（ユーザー所有） | アプリ内LLM |
| 共有層 | **EditCommands（同一）** | **EditCommands（同一）** |
| 追加実装 | MCPサーバ + IPCブリッジ | チャットUI + LLMアダプタ + llm-proxy |
| LLMコスト負担 | ユーザーのエージェント側 | 本アプリ経由（外部API時は従量） |
| オフライン | ◎ | ローカルモデル選択時のみ◎ |

→ EditCommands を共有することで、③のツール実行部は②と同じコードを使い回せる。③固有なのは「LLMに投げて tool_calls を得る」部分だけ。

---

## 6. リスクと対策

| リスク | 対策 |
|---|---|
| 無料/オフライン方針との相反 | external は**オプトイン**・既定OFF。ローカルモデル経路を用意。決定的編集は LLM 不要で温存 |
| LLM の誤編集 | function calling に限定（自由実行不可）＋破壊的操作は人間承認＋全操作 undo 可 |
| APIキー漏洩 | main 保持・キーチェーン・renderer/プロジェクトに出さない・gitignore |
| ハルシネーション（存在しないclip等） | 実行前に getTimeline で照合、未知IDはエラーで弾く |
| コスト/レート | ターン内ツール実行上限、長尺文字起こし等はジョブ化、課金注意の明示 |

---

## 7. 段階的実装ステップ

1. EditCommands（②と共有）が動いている前提。
2. preload に `llmChat` 追加 → `apps/chat` の `llm-proxy.js`（external: Anthropic/OpenAI互換の HTTPS 中継）。
3. `chat-panel.js`：最小チャットUI（履歴・入力・確認トグル）。
4. オーケストレータ：getTimeline→LLM→tool_calls→（確認）→EditCommands.run→結果表示の1ループ。
5. まず読み取り＋`cut_silence`/`add_telop` の数ツールで「無音消してテロップ付けて」を通す。
6. ローカルモデル経路・APIキー設定UI・複合指示の多ターン化・履歴グルーピングを追加。

**最小デモ**: チャットに「この動画の無音を全部消して」→ getTimeline→各clipに `cut_silence`→「12箇所・8.3秒削除しました（↩取り消し）」が出ればコンセプト成立。②のデモと同じゴールを、アプリ内LLMで達成する形。
